# 被微服务多仓库与 Git 冲突折磨疯了？推荐一款免费开源的一体化开发工作台神器！

平时写代码，很多小伙伴（包括我自己）日常都习惯用 VS Code、Cursor、Sublime 或者命令行终端，轻巧又灵活。

但相信很多人都有过同一种折磨：
1. **复杂分支合并冲突**：一旦遇到多分支冲突，手动在代码里改 `<<<<<<< HEAD` 简直提心吊胆，生怕手滑删掉了别人写的逻辑，或者漏删了冲突标记导致 CI 流水线直接挂掉；
2. **多微服务启动繁琐**：前后端分离或者微服务架构下，每次开机都要开 5~8 个黑框（CMD/PowerShell）逐个启动后端服务、前端 dev、网关，桌面乱七八糟，退出时还经常残留孤儿进程占着端口；
3. **想用 IDEA 的 Git 又嫌重**：IntelliJ IDEA / WebStorm 的 3-Way Merge 和提交体验公认是行业天花板，但动辄吃 2~4GB 内存，为了合几个代码或开几个微服务启动庞大 IDE，电脑风扇狂转发烫。

组里资深同事给我推了一个在 GitHub 迅速走红的开源神器 —— **OmniGit**。试用了一周后，直接把它固定在了我的任务栏，今天忍不住自发安利给大家！

## 一、什么是 OmniGit？

简单一句话总结：**它把 JetBrains 最受好评的 Git 提交体验与三方冲突合并（3-Way Merge）完整抽离出来，同时深度融入了「多工程源码资源管理」、「Monaco 代码编辑与 Markdown 实时渲染」、「VS Code 级终端 Dock」以及「多微服务启动与统一脚本编排中心」，做成了一个启动仅需 1 秒、超轻量秒开的独立一体化开发工作台！**

![OmniGit 全景动态演示](https://raw.githubusercontent.com/BucanYu/OmniGit/main/docs/images/omnigit_demo.gif)

项目完全免费开源（MIT 协议），支持 **Windows** 和 **macOS**，所有代码与操作都在本地沙箱离线回环执行，100% 离线数据隐私安全。

## 二、实际用下来，这几个杀手级功能太击中痛点了

### 1. 🎯 原生级 3-Way Merge 可视化冲突解决 (Git 核心)
点击遇到冲突的文件，直接呼出标准的三栏比对器：
- **左栏**：本地原有改动 (Yours)
- **中栏**：最终合并结果 (Result)
- **右栏**：远程传入的改动 (Theirs)

中间带有**双向合并箭头**，点击一下即可智能采纳改动或丢弃，中间实时更新预览。更绝的是：
- **防漏提语法拦截**：如果代码里还有未解决的 `<<<<<<<` 标记，客户端坚决阻止提交；
- **外部冲突消除自愈**：你在惯用的 VS Code 改完冲突保存，OmniGit 后台自动感知并完成 `git add` 暂存，冲突秒解除；
- **中文路径全支持**：底层全自动注入反转义，哪怕中文文件夹深至十几层，也绝不乱码。

### 2. 🛠️ 多微服务启动与脚本统一编排中心 (全新重磅特性！)
这绝对是多工程开发者的福音！
- **脚本自动发现**：自动扫描所有工程下的 `package.json` scripts、`.bat`、`.sh` 启动脚本；
- **一键全部启动/停止**：顶部一键拉起所有微服务，再也不用手动开一堆黑窗口，右上角实时绿灯角标显示运行服务数；
- **彩色 ANSI 实时日志流**：原生支持色彩渲染与 OSC 标题过滤，支持智能自动贴底滚动；
- **孤儿进程守护**：退出时级联终止进程树，彻底告别后台残留 Node/Java 进程霸占端口的恶梦。

### 3. 🚀 免检出精细化挑选推送 (Selective Push)
敏捷迭代中，修 Bug 的提交和写大需求的提交经常交织在一起。OmniGit 提供了免切分支的精细化推送：
- 待推送提交列表带独立复选框，自由勾选想推的 Commit；
- 支持将选中的 Commit **直推远程分支**，或者一键**抽取为独立的补丁分支 (Patch Branch)** 发起 PR，全程完全不污染当前本地工作分支！

### 4. 💻 Monaco 源码编辑、同名标签消歧与 Markdown 实时渲染
- 内置与 VS Code 同源的 Monaco Editor，秒开高亮；
- **智能标签消歧**：打开不同微服务工程里的同名文件（比如好几个 `package.json`）时，标签栏自动提取上级目录区分；
- **Markdown 实时双栏渲染**：中缝鼠标自由拖拽调节比例、双击居中 50:50，支持本地相对路径图片离线渲染。

### 5. 🖥️ 深度对齐 VS Code 体验的集成终端 Dock
- 底部多标签 PTY 并发（PowerShell、Git Bash、CMD）；
- 严格遵循 VS Code 图标语言（`-` 抽屉收起、`🗑️` 销毁会话、`^`/`v` 展开折叠）；
- 终端标签支持双击重命名。

### 6. ⚡ 独创的“一键撤销合并 (Undo Merge)”安全回退
以前执行 `git merge` 之后如果合错了想反悔，得敲复杂的 `git reset` 或查 reflog。OmniGit 顶栏常驻“1-Click 撤销合并”，智能嗅探合并节点并带二次确认，一秒无损回滚。

### 7. 🚀 启动只需 1 秒，内存仅几十兆，安装包仅 76MB！
平时日常驻留后台内存只有 **60MB** 左右；安装包经过 LZMA 高压缩比深度优化，仅有 **76MB**，秒下秒装。
